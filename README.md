# 🧠 AI-Integrated Blog Platform

A full-stack blog application where users can generate articles using AI, write with a rich text editor, and manage content through a powerful admin dashboard.

---

## 🚀 Features

- ✍️ AI-powered blog generation using OpenAI API
- 🖊️ Rich text editing with React Quill
- 🧑‍💼 Role-based authentication (User/Admin)
- 📂 Blog categories and filtering
- 💬 Comment system with admin approval
- 🖼️ Image upload via Cloudinary
- 🔐 JWT-based authentication
- 🔍 Blog search and filter functionality
- 🌐 Fully responsive design

---

## 🛠️ Tech Stack

- **Frontend:** React.js, React Quill, Axios, Tailwind CSS
- **Backend:** Node.js, Express.js, MongoDB, Mongoose
- **Authentication:** JWT (JSON Web Tokens)
- **AI Integration:** OpenAI API
- **Media Handling:** Cloudinary
